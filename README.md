# Task Manager

Small task app built with React, Vite and Tailwind CSS.

## Features
- Add, complete, edit (double click) and delete tasks
- Filter: all / active / done
- Tasks are saved in localStorage

## Run
```bash
npm install
npm run dev
```

## What I learned
- Managing state with `useState` and keeping it in sync with localStorage using `useEffect`
- Splitting UI into components and passing functions as props
